# Frontend Debugging & Concepts

A hands-on journey to become a more complete Frontend Developer by learning the concepts behind modern web development and practicing real-world debugging.

This repository contains the concepts I learn, broken frontend code, and the solutions I develop while studying.

## 🎯 Goal

The goal of this repository is not just to learn how to build websites, but to understand **why things work, why they break, and how to find and fix problems**.

Topics will gradually cover areas such as:

* Browser fundamentals
* DOM & Rendering
* HTTP & Networking
* JavaScript Runtime
* Browser Storage
* CORS
* Performance
* Web Security
* React Internals
* Next.js Architecture
* Accessibility
* Testing
* Frontend Architecture

## 📂 Structure

Each concept has its own folder:

```text
frontend-debugging/
│
├── 01-browser-rendering/
│   ├── broken/
│   ├── solution/
│   └── README.md
│
├── 02-http/
│   ├── broken/
│   ├── solution/
│   └── README.md
│
├── 03-network/
│   ├── broken/
│   ├── solution/
│   └── README.md
│
└── README.md
```

### `broken/`

Contains intentionally broken code used as a debugging exercise.

### `solution/`

Contains the corrected version after identifying and understanding the problem.

### `README.md`

Contains notes about the concept, the problem, why it happened, and how it was solved.

## 🧠 Learning Method

For each concept:

1. Learn the underlying concept.
2. Study how it works in the browser or frontend environment.
3. Analyze a broken example.
4. Identify the problem.
5. Debug and fix it.
6. Document what I learned.

The main focus is on **understanding and problem-solving rather than memorizing solutions**.
